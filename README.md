# Marketplaces eSIM Integration Service

## Описание проекта
Данный проект представляет собой веб-сервис на базе Flask, предназначенный для автоматизации продаж туристических eSIM с пакетами интернета через популярные маркетплейсы (в первую очередь Яндекс Маркет и Ozon). 

Сервис выступает мостом между торговой площадкой, где клиент совершает покупку, и телеком-провайдером, который осуществляет физический выпуск профиля eSIM.

## Бизнес-логика
Главная задача сервиса — обеспечить бесшовный процесс получения виртуальной сим-карты из-за рубежа для путешественников. Цикл работы выглядит следующим образом:
1. **Покупка на маркетплейсе:** Клиент приобретает тариф (пакет интернета для выбранной страны) на маркетплейсе.
2. **Обработка заказа:** Модуль `orders_handler.py` фиксирует новый заказ, а сервисы интеграции (например, `yam_core`) обмениваются статусами с площадкой.
3. **Эмиссия eSIM:** Через интеграцию с API телеком-провайдера (`monty_api.py`) сервис запрашивает и получает новый профиль eSIM с привязанным пакетом данных для нужной страны.
4. **Генерация ссылки:** Сервис создает уникальную и безопасную веб-ссылку с ограниченным сроком действия для конкретного клиента (`link_for_marketplace/generate_link_method.py`).
5. **Выдача продукта:** Перейдя по ссылке, клиент попадает на специальную посадочную страницу (`welcome.html`), где получает свой QR-код для установки eSIM и инструкции.
6. **Поддержка:** На странице выдачи предусмотрены кнопки для быстрой связи с поддержкой через удобные мессенджеры (Telegram, WhatsApp).

## Структура проекта

### Основные модули
* `config.py` — глобальные конфигурационные переменные сервиса.
* `orders_handler.py` — основной скрипт обработки поступающих заказов и маршрутизации логики.
* `monty_api.py` — модуль взаимодействия с API провайдера (Monty) для запроса eSIM и пакетов трафика.
* `yam_core/` — директория с логикой интеграции API Яндекс Маркета (`yam_api.py`) и специфичными запросами к БД (`db_yam.py`).

### Веб-интерфейс выдачи (Flask)
* `link_for_marketplace/flask_core.py` — ядро Flask-приложения, обслуживающего клиентские ссылки.
* `link_for_marketplace/templates/` — HTML-шаблоны страниц:
  * `welcome.html` — страница успешной выдачи QR-кода.
  * `expired_date_page.html` — страница ошибки, если срок действия ссылки истек.
  * `error_page.html` — страница общей ошибки.
* `link_for_marketplace/static/` — статические файлы (CSS-стили `styles.css`, иконки маркетплейсов и мессенджеров, favicons).

### База данных
* `db/db_connection.py` — настройка подключения к базе данных.
* `db/db_queries.py` — общие SQL-запросы для сохранения заказов, сгенерированных ссылок и статусов eSIM.
* `link_for_marketplace/db_link.py` — запросы, специфичные для проверки валидности ссылок и их привязки к заказам.

### Безопасность
* `cert.pem` и `key.pem` — SSL-сертификаты для обеспечения защищенного HTTPS-соединения, что критически важно при передаче QR-кодов eSIM.

## Требования (Requirements)
Все зависимости проекта описаны в файле `requirements.txt`.
* Python 3.8+
* Flask
* Библиотеки для работы с БД (например, psycopg2 или аналоги)
* Библиотеки для API запросов (requests)

## Запуск проекта
1. Клонируйте репозиторий.
2. Создайте виртуальное окружение и установите зависимости:
```bash
pip install -r requirements.txt
```
3.Настройте конфигурацию в config.py (доступы к БД, API ключи Яндекс Маркета и Monty API).
4.Запустите Flask-сервер:
```bash
python link_for_marketplace/flask_core.py
```
(Примечание: для production-среды рекомендуется использовать Gunicorn/uWSGI).
